# Open WebUI 0.8.1 — Stock Baseline Reference

This document describes what a stock Open WebUI 0.8.1 deployment looks like. Anything not listed here is either custom RegOS work or a build artifact.

- **License:** BSD-3-Clause (see `LICENSE`)

## Build Artifacts (Generated)

These directories are created at build time and are NOT part of the source:

- `.svelte-kit/` — SvelteKit build output (generated by `vite build`)
- `node_modules/` — NPM dependencies (generated by `npm install`)
- `__pycache__/` — Python bytecode cache
- `backend/data/` — Runtime data (SQLite DBs, uploaded files, vector stores)
- `uv.lock` — Python dependency lock file
